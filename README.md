# 📷 PhotoGallery — Stunning Moments

A sleek, fully responsive **photo gallery web app** built with pure HTML, CSS, and Vanilla JavaScript. Browse a curated collection of breathtaking photographs, filter by category, search by title, like your favourites, and view them in a beautiful full-screen lightbox — all without any frameworks or dependencies.

## ✨ Features

| Feature | Description |
|---|---|
| 🗂️ **Category Filters** | Filter photos by Nature, City, Abstract, or People |
| 🔍 **Live Search** | Instantly search photos by title or category |
| ❤️ **Like System** | Like/unlike photos with persistent state via `localStorage` |
| 🖼️ **Lightbox Viewer** | Full-screen photo viewer with title, description & category tag |
| ⌨️ **Keyboard Navigation** | Use `←` `→` Arrow Keys to navigate & `Esc` to close the lightbox |
| 📊 **Live Stats** | Real-time count of total visible photos and liked photos |
| 📱 **Responsive Design** | Fully responsive across all screen sizes |
| ⚡ **Lazy Loading** | Images load only when needed for better performance |

## 🗂️ Project Structure

```
PhotoGallery/
├── index.html      # Main HTML structure (header, hero, gallery grid, lightbox, footer)
```

---

## 🧰 Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Custom properties, CSS Grid, Flexbox, glassmorphism effects, keyframe animations
- **Vanilla JavaScript (ES6+)** — DOM manipulation, event handling, `localStorage`
- **Google Fonts** — [Outfit](https://fonts.google.com/specimen/Outfit) typeface
- **Lorem Picsum** — Real placeholder images via `picsum.photos`

## 🚀 Getting Started

No build tools or installations needed. Just open the file in your browser:

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/PhotoGallery.git

# Navigate into the folder
cd PhotoGallery

# Open in browser
start index.html       # Windows
open index.html        # macOS
xdg-open index.html    # Linux
```

Or simply drag and drop `index.html` into any modern web browser.
